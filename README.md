### Research

**[Layered Agentic Retrieval (LAR)](https://github.com/lar-spec/lar)**: a convention for how a business publishes what AI agents need to find, read and act on. Technically, a declarative publisher-side surface: it describes how an institution structures what it publishes so that agents can resolve, parse and act on it deterministically.

- Working paper: Marinoni Moretto, F. (2026). *Layered Agentic Retrieval: A Publishing Architecture for Agent-Native Web Surfaces.* SSRN. [doi.org/10.2139/ssrn.6801118](https://doi.org/10.2139/ssrn.6801118)
- Presented at the [W3C / GS1 Workshop *E-commerce for Humans and AI Agents*](https://www.w3.org/2026/ecommerce-agents/), Zurich, September 2026 (see Standards below)
- Reference implementation: [`lar-spec/lar`](https://github.com/lar-spec/lar) (JSON Schema and worked examples, Apache-2.0)
